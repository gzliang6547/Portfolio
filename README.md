# Goh Zhen Liang — Portfolio

A responsive portfolio presenting software development, AI product engineering, and application security experience.

## Open or host

Open `dist/index.html` in a browser, or upload the contents of `dist` to a static website host. The portfolio does not require a backend, API keys, or a paid AI service to run. Google Fonts load when an internet connection is available; system fonts are used otherwise.

## Edit

- `dist/index.html`: biography, links, project descriptions, and case studies.
- `dist/styles.css`: colours, typography, motion, and responsive layouts.
- `dist/script.js`: architecture-diagram interactions and active navigation.
- `dist/experience.css`: cinematic layout, project themes, and motion styling.
- `dist/experience.js`: live WebGL sculpture, linked project perspectives, scroll reveals, and reduced-motion support.
- `dist/spotlight.css`: immersive introduction, coordinated scene colours, and editorial typography.

The abstract 3D sculpture rotates by dragging or with the arrow keys while focused. Build, AI, and Secure switch its form. System reduced-motion preferences automatically stop continuous movement. A static fallback appears if WebGL is unavailable.

The current contact destination is LinkedIn. GitHub links to the supplied profile; no public project repositories or live project URLs were provided.
